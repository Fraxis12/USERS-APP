🛠️ INSTALACIÓN (PASO A PASO)

Opción A - Instalación Automática (Recomendado)

Linux/Mac:
  cd /ruta/al/proyecto
  chmod +x setup.sh
  ./setup.sh

Windows:
  cd C:\ruta\al\proyecto
  setup.bat

Opción B - Instalación Manual

  1. python3 -m venv venv
  2. source venv/bin/activate (Linux/Mac) o venv\Scripts\activate (Windows)
  3. pip install -r requirements.txt
  4. mysql -u root -p < database.sql
  5. python app.py

🔍 TROUBLESHOOTING RÁPIDO

Error: "No se puede conectar a MySQL"
→ Verifica que MySQL está corriendo: mysql -u root -p

Error: "Base de datos no existe"
→ Ejecuta: mysql -u root -p < database.sql

Error: "No module named flask"
→ Instala: pip install -r requirements.txt

Puerto 5000 en uso
→ Cambia en app.py: app.run(port=8000)

Para más: Ver VERIFICACION.md o README.md
